HoneyHub Bot

HoneyHub Bot is a private internal tool used only by HoneyHub Agency (owner: Toma Georgiev) to manage its own Google Drive and Google Docs files.

Privacy Policy

What data it accesses: The bot accesses only the Google Drive folders and Google Docs of the account owner, in order to create folders and copy document templates.

How data is used: Data is used only to perform these tasks for the owner. It is not sold, shared with third parties, or used for advertising.

Storage: The bot stores only the access token needed to work. No personal data from other users is collected.
